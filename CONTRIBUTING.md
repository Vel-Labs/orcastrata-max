# Contributing To Orcastrata Max

Thank you for helping improve Orcastrata Max.

1. Open an issue for a material feature or behavior change.
2. Keep one change focused on one outcome.
3. Preserve the V1 `codexmax-orchestrator` and `codexmax-*` compatibility IDs.
4. Add tests only for distinct behavior, regressions, or authority boundaries.
5. Run focused tests while you work.
6. Run the full suite only when preparing a package or release freeze.
7. Update public documentation when user-visible behavior changes.
8. Do not include credentials, private data, raw logs, or machine-specific paths.
9. Do not use blanket Git staging. Review the exact files you intend to commit.

By contributing, you agree that your contribution is licensed under
Apache License 2.0.
