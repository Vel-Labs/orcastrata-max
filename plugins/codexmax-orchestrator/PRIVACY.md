# Privacy

Orcastrata Max runs locally and adds no product analytics or hosted account. A
native-only request keeps task content in Codex. An external request can send
the task content approved for the selected OpenCode or Command Code route.
The public provider task path requires read access to the whole admitted
repository root; a named patch does not restrict reads to that patch. Approve
disclosure of that entire root, or use a separate nonsecret input root. Native
task-scope instructions do not create a sandbox; host permissions control access.

Orcastrata Max does not increase Codex plan or subscription limits. It does not
bundle, share, or create external provider accounts. A configured external tool
uses your existing account under that tool's privacy, quota, and billing terms.

The plugin does not read, copy, refresh, or store provider credentials. Local
receipts can contain paths, hashes, model output, and execution metadata. Review
and sanitize them before sharing.
