# Support

Use [GitHub Issues](https://github.com/Vel-Labs/orcastrata-max/issues) for
questions, defects, and feature requests.

Before opening an issue, record the Orcastrata Max version, host version,
operating system, sanitized command or request, and the smallest reproduction.
State whether the failure concerns source, package, installation, tool session,
model selection, or execution.

Do not include credentials, authentication output, private configuration, raw
provider transcripts, or unrelated source files. Use private vulnerability
reporting for security issues.

Vel Labs does not provide a service-level agreement for the open-source
project.
